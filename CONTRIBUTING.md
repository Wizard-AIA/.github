# Contributing

This is the organization-wide default. If the repository you're in has its
own `CONTRIBUTING.md`, follow that one instead — it'll have the specific
setup steps for that codebase.

General shape across Wizard-AIA repos:

1. Fork the repo and branch off its default branch.
2. Keep changes scoped — one PR, one concern.
3. Follow [Conventional Commits](https://www.conventionalcommits.org/) for
   commit messages where the repo enforces it (most do, via commitlint).
4. Open a PR against the default branch; fill in the PR template.

For the core engine specifically, see
[Wizard-AIA/Wizard-w2's CONTRIBUTING.md](https://github.com/Wizard-AIA/Wizard-w2/blob/master/CONTRIBUTING.md).
For contributing a skill rather than code, see
[Wizard-AIA/skills](https://github.com/Wizard-AIA/skills).
