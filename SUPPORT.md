# Support

This is the organization-wide default — most repos in Wizard-AIA point back
to the core engine for support, since that's where the userbase and
maintainer attention actually is.

- **Questions about using Wizard** — the
  [documentation site](https://wizard-aia.github.io/docs/), or
  [GitHub Discussions](https://github.com/Wizard-AIA/Wizard-w2/discussions).
- **Bugs or feature requests** — open an issue on the specific repo
  they concern.
- **Security vulnerabilities** — see [SECURITY.md](SECURITY.md). Never a
  public issue.

This is a small, largely single-maintainer organization. There's no
support SLA; security reports get priority.
