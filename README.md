# Wizard-AIA/.github

Default community health files for every repository in the
[Wizard-AIA](https://github.com/Wizard-AIA) organization.

GitHub falls back to the files in this repo for any org repository that
doesn't define its own copy — `SECURITY.md`, `CONTRIBUTING.md`,
`SUPPORT.md`, issue templates, the PR template, and `FUNDING.yml`. The core
engine repo ([Wizard-AIA/Wizard-w2](https://github.com/Wizard-AIA/Wizard-w2))
defines its own, more specific versions of most of these; this repo exists
so a **new** repo added to the org later — a language SDK, a plugin, a
tool — starts with sane defaults instead of nothing.

Nothing here is meant to be end-user-facing on its own. If you found this
repo looking for Wizard itself, go to
[Wizard-AIA/Wizard-w2](https://github.com/Wizard-AIA/Wizard-w2) or the
[docs site](https://wizard-aia.github.io/docs/).
