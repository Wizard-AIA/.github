## ⚡ Core Pillars

- 🔒 **100% Local-First & Air-Gapped Privacy:** Your datasets and calculations never leave your machine unless you explicitly select a remote cloud provider. Compatible with local [Ollama](https://ollama.com/) and [LM Studio](https://lmstudio.ai/) models.
- ⚡ **True Code Execution:** No hallucinations. Answers are generated by running real Python code and SQL queries against embedded DuckDB and Polars engines.
- 🔄 **Autonomous Self-Correction:** Automatically detects runtime exceptions or missing dependencies, rewrites the analytical script, and verifies outputs before presenting answers.
- 🛡️ **CodeGuard 3-Tier Sandboxing:** Comprehensive AST security screening combined with OS-native isolation (Linux Landlock/seccomp, macOS `sandbox-exec`, Windows Job Objects) or Docker containers.
- 🚀 **High-Throughput Arrow Streaming:** Real-time Apache Arrow IPC streaming capable of rendering millions of rows in the web DataGrid with sub-millisecond overhead.

## 🚀 1-Command Automated Installers

### macOS & Linux
```bash
curl -fsSL https://wizardw2.vercel.app/install.sh | bash
```

### Windows (PowerShell)
```powershell
irm https://wizardw2.vercel.app/install.ps1 | iex
```

### Homebrew (macOS & Linux)
```bash
brew tap Wizard-AIA/wizard && brew install wizard
```

### Docker Compose
```bash
git clone https://github.com/Wizard-AIA/Wizard-w2.git
cd Wizard-w2
docker compose up -d
```

## 📦 Standalone Prebuilt Packages (v1.0.5)

Download the binary bundle for your OS, extract it, and start the agent supervisor:

| Operating System | Architecture | Download Package |
| :--- | :--- | :--- |
| **macOS** | Apple Silicon (M1 / M2 / M3 / M4) | [**`Wizard-v1.0.5-darwin-arm64.zip`**](https://github.com/Wizard-AIA/Wizard-w2/releases/download/v1.0.5/Wizard-v1.0.5-darwin-arm64.zip) |
| **macOS** | Intel x86_64 | [**`Wizard-v1.0.5-darwin-amd64.zip`**](https://github.com/Wizard-AIA/Wizard-w2/releases/download/v1.0.5/Wizard-v1.0.5-darwin-amd64.zip) |
| **Linux** | x86_64 / amd64 | [**`Wizard-v1.0.5-linux-amd64.zip`**](https://github.com/Wizard-AIA/Wizard-w2/releases/download/v1.0.5/Wizard-v1.0.5-linux-amd64.zip) |
| **Linux** | ARM64 / aarch64 | [**`Wizard-v1.0.5-linux-arm64.zip`**](https://github.com/Wizard-AIA/Wizard-w2/releases/download/v1.0.5/Wizard-v1.0.5-linux-arm64.zip) |
| **Windows** | x86_64 | [**`Wizard-v1.0.5-windows-amd64.zip`**](https://github.com/Wizard-AIA/Wizard-w2/releases/download/v1.0.5/Wizard-v1.0.5-windows-amd64.zip) |

```bash
# Extract and launch
./cli/wizard init       # Verifies environment and dependencies
./cli/wizard start      # Launches background supervisor and opens web interface
```
Open **`http://localhost:3000`** in your browser to begin analyzing your data.

## 🛠️ CLI Quick Reference

| Command | Action |
| :--- | :--- |
| `wizard init` | Verify Python/Node environment and configure default models |
| `wizard start` | Start backend, frontend, and open web workbench |
| `wizard stop` | Gracefully shut down all running Wizard daemons |
| `wizard status` | Inspect live supervisor health, PIDs, and active memory usage |
| `wizard logs` | Stream consolidated backend and frontend logs |
| `wizard exec "<query>"` | Run a headless analytical query directly from your terminal |
